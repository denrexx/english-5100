# english-5100

5100 самых частотных слов современного американского английского

Список составлен на основе более 20 миллионов субтитров с YouTube и TikTok

Сайт предназначен для тех, кто уже знаком со словообразованием. Для каждого семейства слов оставлена только самая частотная форма, встретившаяся в субтитрах. Остальные формы и производные слова из того же семейства в список не включены

Пять уровней, тест, фразовые глаголы, повторение ошибок и незнакомых слов. При запуске через Python прогресс сохраняется на сервере и доступен с разных устройств

## Запуск

Нужен Python 3, без дополнительных пакетов

```bash
python3 serve.py
```

Откройте http://localhost:8080

## Доступ с телефона и других устройств

```bash
python3 serve.py --lan
```

Сервер покажет адрес для локальной сети, например `http://192.168.1.101:8080`. Откройте его на устройстве, подключённом к тому же Wi-Fi или локальной сети

Если порт занят:

```bash
python3 serve.py --lan --port 8081
```

Компьютер с сервером должен оставаться включённым. Сервер не меняет настройки интернета или роутера. Если доступ блокируется, проверьте разрешение входящих соединений на выбранный порт и изоляцию устройств в Wi-Fi

Все устройства, открывающие сайт на этом сервере, используют один общий профиль: уровни, текущую карточку, ошибки, незнакомые слова, время занятий и историю. Изменения появляются на других устройствах автоматически

При первом подключении прежний прогресс браузера объединяется с общим профилем. Исходную копию можно скачать в настройках. При одновременных изменениях сервер отклоняет устаревшее сохранение и устройство получает актуальный прогресс

База SQLite находится вне сайта: `~/.local/share/english-5100/progress.sqlite3`. Она сохраняется при перезапуске сервера и не публикуется в GitHub. Для отдельного профиля укажите другой файл:

```bash
python3 serve.py --lan --state-file /path/to/progress.sqlite3
```

## Управление

- **1, 2, 3**: выбрать перевод
- **4**: «Не знаю»
- **Space**: произношение в тренировке
- **P**: пауза

Озвучка в тренировке включена по умолчанию. На главной странице звука нет: нажмите на карточку, чтобы открыть следующее случайное слово. После загрузки страницы первой всегда будет world. Следующие карточки выбираются случайно из слов 1–3000 и не повторяются до перезагрузки страницы

Уровни: 1–1000, 1001–2000, 2001–3000, 3001–4000, 4001–5100

Секундомер показывает активное время. При бездействии от 10 секунд весь промежуток ожидания исключается. Следующее нажатие продолжает отсчёт

## Размещение

Сайт также работает на статическом HTTPS-хостинге. Загрузите `index.html`, `app.js`, `sync.js`, `style.css`, `tokens.css`, `data.json`, `sw.js`, `manifest.webmanifest` и папку `audio`

На статическом хостинге, включая GitHub Pages, прогресс хранится в браузере. Для общего профиля нужен сервер `serve.py`, к которому подключаются все устройства

На localhost и HTTPS карточки сохраняются для работы без интернета. На телефоне по обычному HTTP-адресу локальной сети нужен работающий сервер. Озвучка кэширует последние 80 записей там, где доступен service worker. Для отсутствующей или неподдерживаемой записи используется английский голос браузера, если он установлен
