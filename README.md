# english-5100

5100 частотных слов современного разговорного американского английского с переводом и произношением.

Сайт для повторения: пять уровней, тест, фразовые глаголы, список ошибок и незнакомых слов. Прогресс сохраняется в браузере.

## Запуск

Нужен Python 3, без дополнительных пакетов.

```bash
python3 serve.py
```

Откройте http://localhost:8080. Если порт занят: `python3 serve.py --port 8081`.

## Управление

- **1–3** — выбрать перевод.
- **4** — «Не знаю».
- **Space** — произношение.
- **P** — пауза.

Озвучка включена по умолчанию. Настройки позволяют её отключить, скачать или восстановить копию прогресса.

Уровни: 1–1000, 1001–2000, 2001–3000, 3001–4000, 4001–5100.

Секундомер показывает активное время. При бездействии от 10 секунд весь промежуток ожидания исключается. Следующее нажатие продолжает отсчёт.

## Размещение

Сайт работает на статическом HTTPS-хостинге. Загрузите `index.html`, `app.js`, `style.css`, `tokens.css`, `data.json`, `sw.js`, `icon.svg`, `manifest.webmanifest` и папку `audio`.

После первой загрузки карточки доступны без интернета. Озвучка кэширует последние 80 записей; остальные доступны при работающем сервере. Для отсутствующей или неподдерживаемой записи используется английский голос браузера, если он установлен.
